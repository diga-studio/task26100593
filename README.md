# orgchart

按生效日期管理部门归属的 Go 库，组织历史保存在进程内存中，供上层人事系统直接调用。

## 用法

```go
c := orgchart.New("R", []string{"A", "B"})          // 唯一根部门 + 固定部门集合
c.LoadInitial("A", []orgchart.Interval{             // 载入初始历史（调用方保证合法）
    {Parent: "R", From: day("2000-01-01")},
})
err := c.ApplyBatch([]orgchart.Adjustment{          // 整批提交，全部接受或全部拒绝
    {Dept: "B", Parent: "A", From: day("2024-03-01")},              // To 为零值表示永久
    {Dept: "C", Parent: "A", From: day("2024-01-10"), To: day("2024-01-20")},
})
chain := c.Chain("B", day("2024-03-01"))            // [B A R]，从本部门到根
```

## 语义

- 日期区间为 `[From, To)`：起日包含、止日不包含；`To` 为零值表示永久。
- 调整只替换区间内归属，区间外已有安排原样保留；支持追溯调整。
- 每批按全部调整共同生效后的结果判定，输入顺序不影响结果。
- 校验保证从 2000-01-01 起任意一天，每个部门沿上级链都能到达根（无自环、无多部门环）。
- 任一条目导致违规则整批拒绝，已提交历史保持不变。
